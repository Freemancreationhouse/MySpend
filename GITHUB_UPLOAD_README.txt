MY SPEND V1 - GITHUB BUILD

Upload ALL contents of this folder to the ROOT of your GitHub repository.
Do not upload the outer MySpend_GitHub_V1 folder as another nested folder.

After upload/commit:
1. Open the repository's Actions tab.
2. Open "Build My Spend APK".
3. Wait for the build to finish with a green check.
4. Open the completed run.
5. Under Artifacts, download "MySpend-V1-APK".
6. Extract it and install app-debug.apk on your Android phone.

Every push to main/master will build a fresh APK automatically.
