# My Spend V1.1 Safe
Privacy-first Android personal spending tracker.

## Safety baseline
- No INTERNET permission
- No SMS permission
- No notification-listener service
- No Accessibility service
- Local SQLite storage only

## Features
- Premium dashboard UI
- Income / expense entry
- Transaction timeline
- Category analytics
- CSV import
- GitHub Actions APK build

Push to GitHub, open Actions, run **Build My Spend V1.1 Safe APK**, then download the `MySpend-V1.1-Safe-APK` artifact.
